The funniest one-line fortune cookie message for a software engineer — an entry for the [Fortune Cookie Funnies for Engineers](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a) bounty on make.fun.

> Your code will work on the first try, and that will worry you more than any bug.

## Why this line wins

A fortune cookie is supposed to bring good news — and this one does, then turns it into the engineer's worst dread in the same breath. Every engineer knows the feeling: code that works on the first try is not a relief, it is a mystery, because you have no idea *why* it works and therefore no idea when it will stop. The joke lands on the first read, it is specific to the engineer's world (no generic "tall dark stack trace" wordplay), it is not a mug or conference-slide line, and it is tight: every word earns its place, with the funniest word — *bug* — sitting at the very end. See [CANDIDATES.md](CANDIDATES.md) for the nine lines it beat and why.

## Run it

```sh
python3 main.py
```

Writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it. Verify it:

```sh
python3 main.py --check
```

Standard library only, deterministic — the same bytes on every run.
